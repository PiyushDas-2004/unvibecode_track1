## Day-2 summary

Coming back tomorrow, a developer has to: remember the long command; remember `--output`; wait 15–25 s for a re-upload; open a browser; find the file again in an all-files graph; and work out on their own whether anything changed. **The tool keeps no state between runs**, and the output answers no question that comes up in a normal working day. The fast, deterministic part (code map in 1.5–3.7 s server time, identical across runs) is the piece that can carry a habit. The slow LLM part was broken throughout the trial.
